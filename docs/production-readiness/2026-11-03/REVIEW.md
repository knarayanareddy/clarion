# Clarion review

## Scope and verdict

**Implementation / hackathon prototype**, reviewed at `4584cc036d75ab0132cd741461a3f1e5be97d7db` on `main`. This is a static, partial review, not a production assessment. The repository describes a Slack-native accessibility assistant and claims a live sandbox deployment; the claim has not been independently checked. Runtime, build, tests, installation, live Slack, OpenAI, MCP, and accessibility checks were **NOT RUN**. The single historical CI success is scoped below.

The strongest immediate concerns are incomplete thread and member pagination, an ineffective test/lint gate, and private workspace content crossing an external model boundary without a verified data-governance policy. The corrective sequence is in [REMEDIATION_PLAN.md](REMEDIATION_PLAN.md).

## Architecture and product boundary

`src/app.ts` starts a Slack Bolt Socket Mode app, initializes real-time search, and registers agent, shortcut, command, event and action listeners ([app.ts:20-42](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/app.ts#L20-L42)). The shortcut fetches Slack thread messages, calls the model and posts an ephemeral card; image events retrieve a private image and send model descriptions as DMs. Profiles and welcome state use local SQLite. Separately, `src/mcp/server.ts` is a stdio MCP entry point, not a nested web app ([server.ts:1-13](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/mcp/server.ts#L1-L13)). Slack, the selected model provider and persistent storage are external operational dependencies. Other listeners, MCP tools, the manifest and deployment topology were not traced.

## Findings ledger

- **C1 — High, confirmed static: thread summary silently omits later pages.** [`shortcuts.ts:36-50`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/shortcuts.ts#L36-L50) requests `limit: 50`, reads only that response and calls `simplifyText`; no cursor is followed in this handler. A longer or paginated thread can produce a partial rewrite without a warning. Follow cursors under an explicit bound and disclose truncation; test multiple pages and failures.
- **C2 — Medium, confirmed static: member enumeration stops at one page.** [`events.ts:38-47`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/events.ts#L38-L47) requests `limit: 200` once and intersects only `resp.members` with enabled users. Eligible channel members beyond that response may not receive descriptions. Paginate with a bound and fail closed if membership cannot be established.
- **C3 — Medium, confirmed static: missing shortcut message is dereferenced before validation.** [`shortcuts.ts:15-21`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/shortcuts.ts#L15-L21) reads `message.ts` before `if (!message ...)`. A malformed or unexpected payload throws instead of reaching the intended error response. Validate the payload first; test the actual registered handler with absent fields.
- **C4 — High, confirmed static / historical CI: quality gates overstate what a green run establishes.** [`package.json:6-13`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/package.json#L6-L13) has `test: echo "no tests yet"` and an echo-only lint. [CI lines 13-23](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/.github/workflows/ci.yml#L13-L23) uses `npm install` then only `npm run build`. The [successful run](https://github.com/knarayanareddy/clarion/actions/runs/36902541430) is for the pinned SHA, not evidence of behavior, lint, reproducible installation, or current deployment health. Replace placeholders and make CI run meaningful gates.
- **C5 — Medium, confirmed static: credential configuration disagrees across entry and model layers.** [`app.ts:10-17`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/app.ts#L10-L17) requires `OPENAI_API_KEY`, while [`llm.ts:4-12`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/core/llm.ts#L4-L12) accepts `OPENROUTER_API_KEYS` instead. An otherwise configured multi-key-only Slack process exits before starting. Align validation with the supported provider configuration without logging key values.
- **C6 — High, unverified risk: privacy, consent and instruction boundaries need evidence.** [`shortcuts.ts:38-50`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/shortcuts.ts#L38-L50) forwards fetched message text for model processing; [`events.ts:54-78`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/events.ts#L54-L78) downloads private images and submits them per recipient. [`profiles.ts:14-19,90-93`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/core/profiles.ts#L14-L19) defaults `describeImages` to true and selects saved rows enabled for images. Whether the modal obtains informed image opt-in, whether Slack scopes and MCP access isolate users, and provider retention or prompt-injection controls are adequate remain unverified. Establish consent, authorization, data-flow and hostile-content tests before real-workspace use; do not infer an exploit or existing violation.
- **C7 — Medium, unverified risk: recovery and operational controls are unspecified in sampled code.** [`profiles.ts:24-42`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/core/profiles.ts#L24-L42) opens `DB_PATH` or `./clarion.db`, storing accessibility preferences and welcome state. Backup, encryption, retention, deletion, restore and deployment health were not established. Define and observe them against an owner-approved deployment.

## Five-discipline assessment

**Correctness:** C1–C3 and C5 are code-level defects; the parser in [`llm.ts:141-158`](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/core/llm.ts#L141-L158) falls back to the original text on invalid JSON, so failures need visible, accessible handling. Unread code may contain additional defects.

**Automation/testing:** C4 limits the meaning of CI. No tests, lint, typecheck, builds or lockfile verification were executed here. The tree contains `TESTING.md` and `test-report.md`, but their contents were not inspected.

**DevOps/operations:** README asserts a live sandbox VM ([README.md:5-7](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/README.md#L5-L7)); neither uptime nor configuration was checked. Socket reconnect, costs, persistent storage, monitoring and restore are open (C7).

**OWASP/security:** The app refuses startup without its listed credentials and SQLite queries shown are parameterized ([app.ts:10-17](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/app.ts#L10-L17), [profiles.ts:48-52](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/core/profiles.ts#L48-L52)). This does not prove authorization, secret rotation, dependency integrity or protection against model instruction injection. The image fetch attaches a bot bearer token to a URL from the event ([events.ts:54-60](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/events.ts#L54-L60)); URL provenance and redirect handling require review, not an assumed exploit. C6–C7 cover data protection.

**UI/UX/accessibility:** The Slack shortcut acknowledges first and supplies fallback text ([shortcuts.ts:11-13,99-105](https://github.com/knarayanareddy/clarion/blob/4584cc036d75ab0132cd741461a3f1e5be97d7db/src/listeners/shortcuts.ts#L99-L105)). That is useful design evidence, not an accessibility pass. Test Slack screen-reader announcements, profile consent, missing/paginated content, generated descriptions and private delivery with users. There is no observed web UI to assess.
